# Castline — cast for the audience, not just the headline

Castline is an AI casting-audience agent. It uses the Qloo Taste AI API to score a casting shortlist on audience **fit** (do this person's fans already love projects like ours?) and **reach** (which audience segments would they add?), then proposes the ensemble with the widest combined reach.

Work in progress for the Qloo Agentic Hackathon 2026. Full docs coming.
